\chapter{Development Environment and Build}
\label{chap:development-environment-and-build}

This chapter is part of the new editorial skeleton for the developer manual. It keeps the build chapter anchored while the real developer workflow is reorganized.

\noindent\textbf{Objective.} Describe the environment and build surface used by developers working on GenESyS.

\noindent\textbf{Audience.} Contributors, maintainers, and anyone who needs to configure the project from source.

\noindent\textbf{Scope.} Cover the toolchain baseline, build presets, and the expectations for a reproducible local development setup.

\noindent\textbf{Status.} Temporary skeleton only; the concrete build instructions will be migrated later.
