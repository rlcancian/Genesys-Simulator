\chapter{Worker Usage and Security}
\label{chap:worker-usage-and-security}

This chapter is part of the new editorial skeleton for the user manual. It keeps the Worker chapter present while the security and deployment constraints are rewritten.

\noindent\textbf{Objective.} Explain how the Worker is used and what security assumptions bound its operation.

\noindent\textbf{Audience.} Operators and integrators who need to understand the Worker boundary before enabling it.

\noindent\textbf{Scope.} Focus on supported usage, local-only constraints, and the safety limits that distinguish execution from public exposure.

\noindent\textbf{Status.} Temporary skeleton only; the detailed security narrative will be filled in later.
