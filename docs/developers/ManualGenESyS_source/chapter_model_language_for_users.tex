\chapter{Model Language for Users}
\label{chap:model-language-for-users}

This chapter is part of the new editorial skeleton for the user manual. It preserves the user-facing language chapter while the formal explanation is reorganized.

\noindent\textbf{Objective.} Introduce the model language as a readable description of the same model shown in the GUI.

\noindent\textbf{Audience.} Users who want to inspect or author model text after learning the graphical workflow.

\noindent\textbf{Scope.} Keep the focus on syntax, user-level semantics, and the relationship between text and the visual model representation.

\noindent\textbf{Status.} Temporary skeleton only; the complete language walkthrough will be provided later.
