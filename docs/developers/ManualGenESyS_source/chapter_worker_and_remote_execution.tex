\chapter{Worker and Remote Execution}
\label{chap:worker-and-remote-execution}

This chapter is part of the new editorial skeleton for the developer manual. It preserves the worker chapter while the remote-execution boundary is rewritten.

\noindent\textbf{Objective.} Explain the Worker architecture and the supported remote-execution model.

\noindent\textbf{Audience.} Developers and maintainers who need to reason about remote invocation, isolation, and deployment constraints.

\noindent\textbf{Scope.} Focus on the Worker boundary, the local/private execution assumptions, and the current support limits.

\noindent\textbf{Status.} Temporary skeleton only; the operational details will be migrated later.
