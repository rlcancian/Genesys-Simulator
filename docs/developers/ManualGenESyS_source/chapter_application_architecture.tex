\chapter{Application Architecture}
\label{chap:application-architecture}

This chapter is part of the new editorial skeleton for the developer manual. It keeps the application architecture chapter in place while the multi-application view is reorganized.

\noindent\textbf{Objective.} Describe how the executable applications are organized at a high level.

\noindent\textbf{Audience.} Developers who need to understand how the source tree maps to the runnable applications.

\noindent\textbf{Scope.} Focus on application families, shared responsibilities, and the boundaries between user and support binaries.

\noindent\textbf{Status.} Temporary skeleton only; the architecture walkthrough will be refined later.
