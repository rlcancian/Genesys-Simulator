\chapter{Model Editing in the GUI}
\label{chap:model-editing-in-the-gui}

This chapter is part of the new editorial skeleton for the user manual. It keeps the editing workflow chapter in the book while the detailed guidance is rewritten.

\noindent\textbf{Objective.} Explain how users edit a model through the graphical interface.

\noindent\textbf{Audience.} Users who need to modify components, connections, and properties inside the GUI.

\noindent\textbf{Scope.} Cover the editing actions, the structure of the workspace, and the user-visible editing constraints that shape model maintenance.

\noindent\textbf{Status.} Temporary skeleton only; the full editing guide will be expanded later.
