This chapter is part of the new editorial skeleton for the developer manual. It keeps the integrations chapter present while the external interfaces are formalized.

\noindent\textbf{Audience.} Developers who need to connect GenESyS to other services or auxiliary workflows.

\noindent\textbf{Scope.} Cover supported integrations, integration boundaries, and the limitations that apply before any broader exposure is approved.

\noindent\textbf{Status.} Temporary skeleton only; the concrete integration guide will be added later.
