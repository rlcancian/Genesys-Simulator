\chapter{Testing and Validation}
\label{chap:testing-and-validation}

This chapter is part of the new editorial skeleton for the developer manual. It keeps the testing chapter visible while the validation matrix is rebuilt.

\noindent\textbf{Objective.} Document the available tests and the validation practices used in the repository.

\noindent\textbf{Audience.} Developers, maintainers, and reviewers who need to judge change quality.

\noindent\textbf{Scope.} Focus on unit tests, smoke tests, validation evidence, and the current limits of test coverage.

\noindent\textbf{Status.} Temporary skeleton only; the detailed testing guide will be written later.
