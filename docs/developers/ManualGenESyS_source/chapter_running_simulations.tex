\chapter{Running Simulations}
\label{chap:running-simulations}

This chapter is part of the new editorial skeleton for the user manual. It protects the simulation-execution chapter slot while the worked examples are migrated.

\noindent\textbf{Objective.} Document the visible steps required to launch and monitor a simulation run.

\noindent\textbf{Audience.} Users who already have a model loaded and want to execute it safely.

\noindent\textbf{Scope.} Focus on run commands, basic parameter choices, and the immediate signals that a simulation started correctly.

\noindent\textbf{Status.} Temporary skeleton only; the execution narrative and concrete examples will come later.
