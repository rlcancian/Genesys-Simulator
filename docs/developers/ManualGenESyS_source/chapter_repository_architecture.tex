\chapter{Repository Architecture}
\label{chap:repository-architecture}

This chapter is part of the new editorial skeleton for the developer manual. It preserves the repository architecture slot while the structure is rewritten around the canonical tree.

\noindent\textbf{Objective.} Explain how the repository is organized and how the source tree is partitioned.

\noindent\textbf{Audience.} Developers who need a map of the codebase before changing modules or documentation.

\noindent\textbf{Scope.} Focus on repository layout, major top-level directories, and the reading path for technical work.

\noindent\textbf{Status.} Temporary skeleton only; the final architectural map will be expanded later.
