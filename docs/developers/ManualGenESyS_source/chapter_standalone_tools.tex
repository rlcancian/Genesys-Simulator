\chapter{Standalone Tools}
\label{chap:standalone-tools}

This chapter is part of the new editorial skeleton for the user manual. It preserves the slot for helper applications while the content is reorganized around the new tree.

\noindent\textbf{Objective.} Present the standalone tools that accompany GenESyS and explain how they fit the user workflow.

\noindent\textbf{Audience.} Users who need auxiliary tools for analysis, optimization, or specialized workflows.

\noindent\textbf{Scope.} Keep the chapter limited to user-facing tools, their intended purpose, and the level of support currently documented.

\noindent\textbf{Status.} Temporary skeleton only; the tool-by-tool guide will be authored later.
