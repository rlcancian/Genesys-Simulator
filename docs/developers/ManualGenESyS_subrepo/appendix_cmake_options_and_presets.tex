\chapter{CMake Options and Presets}
\label{chap:appendix-cmake-options-and-presets}

This appendix summarizes the CMake surface that the current manual already
documents. It is not a substitute for \texttt{CMakePresets.json}; it is a
navigation aid for readers who want the active names in one place.

The configuration families are based on the current preset inventory
documented in the build chapter and the current target matrix. \index{CMake}
\index{CMake presets}

current chapter set does not claim a separate release-oriented CMake preset
unless a later validated chapter says otherwise.
