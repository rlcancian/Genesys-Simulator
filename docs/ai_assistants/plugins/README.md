## Naming note

The guide names are documentation categories. They may not exactly match every source subfolder name. Always inspect the real source tree before editing code.

## Common rule

Historical notes from `docs/ai_assistants/oldies/` are retained for traceability, but each technical claim must be revalidated against the current branch before implementation.
