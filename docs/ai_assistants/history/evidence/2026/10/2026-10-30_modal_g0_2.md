## Codec contract

The `.gui` section is `Graphical EFSM Network Diagrams`, schema version 1.
It stores Network identity, state IDs/positions, and optional transition
control/label positions. `EFSMTransition` has no persistent ID, so the codec
uses its global zero-based position in the transition list. This is safe under
the existing `.gen` contract because save and load iterate that list in the
same order. Source/destination and exact names, including empty names, are
integrity checks; the `name` field is mandatory in v1. Invalid or stale
references are dropped without modifying `.gen` topology or mathematics.
Unknown versions and malformed lines are ignored. Files without the section
remain compatible.

The existing `.gen` loader omits default-valued empty transition names and
reconstructs those omitted values as `T<ordinal>`. No kernel change is allowed
in this correction. Therefore the direct codec regression proves that parallel
empty-name transitions remain distinct and reject a rename, while the full
`.gui`/`.gen` round-trip regression uses explicit transition names. Future work
may need an explicit invalidation/migration policy if transition order or the
semantic name-default contract changes.
