# GUI-006 through GUI-009 implementation evidence

## Confirmed causes and corrections

- **GUI-006:** The generic boolean control parsed text through `std::istringstream >> bool` without `std::boolalpha`, while the Qt editor supplied `true` and `false`. The control now accepts `true`, `false`, `1`, and `0`, and rejects invalid text before calling the setter. The displayed Assignment property is `DestinationIsAttribute`; the persisted `assignIsAttrib` field is unchanged.
- **GUI-007:** `Search` and `Remove` created a Queue in `_createEditableDataDefinitions()` whenever their reference was empty. They now preserve an empty reference during editing and model checks, retain existing Queue choices, and allow explicit creation. A regression test also found that the generic class control advertised typed creation without implementing it. The typed creation method now checks the announced type and delegates to the existing explicit creator.
- **GUI-008:** The Seize selection path uses `Index` for `SPECIFICMEMBER`; it does not require `SaveAttribute`. The corresponding Release path reads `SaveAttribute` to identify the acquired Set member. Seize now validates the Index expression; Release reports a missing required attribute in its own model check.
- **GUI-009:** The DISC grammar discarded the supplied parameters and called `sampleDiscrete(0,0)`. It now collects ordered cumulative-probability/value pairs, validates the CDF and finite values, converts cumulative probabilities to masses, and draws once through the sampler. The array sampler now uses a strict upper-bound comparison so a zero-mass outcome cannot be selected when the draw is exactly zero. Generated parser files were regenerated with Bison 3.8.2.

## Local validation

The baseline was a clean checkout of `origin/WorkInProgress` at `d6a0db1f1066f9220267f9aefbc692c1f17a38bf`. Toolchain: GCC 13.3, CMake 3.28.3, Ninja 1.11.1, Qt 6.4.2, Bison 3.8.2, and Flex 2.6.4.

- Focused Qt regression for the real Search/Remove “Create new Queue” combo action: **PASS**, 1/1 after fixing typed creation. The test initially failed and identified a previously untested generic control path.
- Final `cmake --build --preset tests-unit --target genesys_tests --parallel 4` and `ctest --preset tests-unit --output-on-failure -j 4`: **PASS**; 2,219 executed, zero failed, four disabled, two skipped because their local reference fixtures are absent.
- Final `cmake --build --preset tests-kernel-unit --parallel 4`: **PASS**. Its integrated test command completed. The first complete `ctest --preset tests-kernel-unit --output-on-failure -j 4` had one failure in the pre-existing `GraphicalRoundTrip.InvalidDecideExpressionLoadsWithoutTerminatingGui` test: loading returned a model without the expected Decide. That case then passed in 20/20 isolated repetitions, and a second complete CTest run passed with 2,230 executed, zero failed, four disabled, and two skipped. The one-time failure remains an unexplained intermittent result and is not counted as resolved by this patch.
- Final `cmake --build --preset gui-app --parallel 4`: **PASS**, including the GUI executable. A bounded eight-second startup using the offscreen Qt platform and isolated configuration directory reached application initialization without a crash; the process was then stopped by the planned timeout. This is startup evidence, not an interactive desktop test.
- Manual LaTeX compilation and `docs/ManualGenESyS.pdf` regeneration: **PASS**; 400 pages.
- `python3 scripts/validate-ai-docs.py`: **PASS**.
- Before the final typed-creation adjustment, the complete `tests-unit` and `tests-kernel-unit` CTest suites, smoke tests, and GUI build passed. The final runs are recorded separately after they complete; earlier results alone do not validate the final patch.
